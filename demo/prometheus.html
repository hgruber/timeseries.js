No Prometheus server is configured, so this page installs a synthetic /api/v1/query_range (a stubbed fetch) that answers rate(node_cpu_seconds_total[1m])-style queries with a generated signal — the real prometheus source runs against it unchanged. Zoom in and the fine tier takes over; zoom out and it cross-fades into the coarse one. Point this at a real server by replacing the stub with url/credentials.
