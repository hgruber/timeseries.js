No InfluxDB server is configured, so this page installs a synthetic fetch stub. The dropdown at the top-right toggles between mode: '1x' (InfluxQL, form-encoded POST /query) and mode: '2x' (Flux, JSON POST /api/v2/query, CSV response). The chart and the cross-fade behaviour are identical in both modes — only the wire format differs. Point this at a real server by replacing the stub with url/token/db.
