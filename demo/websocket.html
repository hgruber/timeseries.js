timeseries.js — WebSocket adapter

rolling PointSeries window from a WebSocket feed

The WebSocket adapter needs a server you bring yourself — there is no synthetic fallback to stub. Point url at a feed that emits one JSON object per tick, supply a transform that maps each message to { t, values }, and the chart keeps a rolling window of the most recent windowMs milliseconds (1 h by default). 

import TimeSeries from '@hgruber/timeseries.js';
import '@hgruber/timeseries.js/src/adapters/websocket.js';
import { attachTooltip } from '@hgruber/timeseries.js/src/tooltip.js';

const ts = new TimeSeries({
  canvas: 'chart',
  sources: [{
    'source-type': 'websocket',
    url: 'wss://example.com/metrics',
    windowMs: 30 * 60 * 1000,                 // 30-minute rolling window
    transform(msg) {
      // msg arrives as the parsed JSON object the server sent.
      return {
        t: msg.timestamp_ms,
        values: { cpu: msg.cpu, mem: msg.mem }
      };
    }
  }]
});

attachTooltip(ts);

Message shape is yours to choose — only transform has to return { t: ms, values: { seriesId: number } }. The adapter maintains the buffer and trims it on every tick; a viewport pan or zoom does not re-open the socket.

Need to close the feed (page teardown, theme switch with a different URL): the underlying WebSocket is reachable as source._ws after init.
