timeseries.js — Zabbix

zoom-adaptive history/trends with a min/avg/max band

resolution:…

No Zabbix server is configured, so this page installs a synthetic api_jsonrpc.php (a fake XMLHttpRequest) that answers history.get and trends.get with a generated signal — the real zabbix source runs against it unchanged. Zoom in and the fine history line takes over; zoom out and it cross-fades into the hourly trends min/avg/max band. Panning prefetches ±50% either side. Point this at a real server by replacing the fake-server block with url/credentials.
